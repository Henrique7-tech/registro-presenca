# Registro de Presença Eletrônico

Sistema web desenvolvido para o Projeto Integrador com o objetivo de gerenciar e controlar o registro de presença de participantes/alunos de forma prática e digital.

## Funcionalidades

- **Cadastro e Registro:** Adição rápida de registros de presença com validação de data e campos obrigatórios.
- **Listagem Dinâmica:** Visualização organizada dos registros salvos.
- **Persistência Local:** Armazenamento de dados diretamente no navegador utilizando `localStorage`, mantendo as informações salvas mesmo após fechar a página.
- **Interface Responsiva:** Layout limpo e adaptável para diferentes tamanhos de tela.

## Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página e formulários.
- **CSS3:** Estilização, layout e controle de exibição de componentes.
- **JavaScript (Vanilla):** Manipulação do DOM, validação de dados e gerenciamento do `localStorage`.
